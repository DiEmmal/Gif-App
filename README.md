# GIF APPLICATION
This is a simple GIF application built in React with TypeScript and Tailwind CSS.

## Get Started
To get started with this project you need to clone the repository, then follow these steps:
1. Install dependencies: `npm install`
2. Copy the `.env.template` file to `.env` and fill in the required fields
3. Start the development server: `npm run dev`

For production, you can use the following command: `npm run build` and `npm run preview`

## Additional Information
This project was my first experience with React.js, I used TypeScript for type safety and Tailwind CSS for styling.
I used the Giphy API to fetch GIFs, more information about the API can be found here: https://developers.giphy.com/
